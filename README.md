# Portofolio Kerja

Website profil dan portofolio kerja profesional. Satu halaman statis, tanpa framework dan tanpa dependensi.

## Isi

- Profil singkat
- Pengalaman kerja: Mekanik, PT Uwu Jump Indonesia (Mei - November 2026)
- Keahlian kerja
- Sertifikasi dan pendidikan: Sertifikat EPTUS, Sertifikat Komputer, Ijazah Pendidikan
- Kontak

## Cara pakai

1. Ganti semua teks di dalam kurung siku di `index.html` dengan data Anda: `[Nama Lengkap]`, `[Kota/Domisili]`, `[Nomor WhatsApp]`, `[Email Aktif]`.
2. Buka `index.html` di browser untuk melihat hasilnya, atau cetak ke PDF lewat tombol Cetak / Simpan PDF di halaman.
3. Mode gelap dan terang tersedia lewat tombol di bagian atas halaman.

## Deploy ke Vercel

Cara paling cepat, lewat dashboard Vercel:

1. Buka vercel.com, lalu pilih Add New, Project.
2. Pilih Import dari GitHub, lalu pilih repositori `portofolio-kerja`.
3. Biarkan semua pengaturan bawaan, lalu tekan Deploy. Selesai, Vercel memberi link live.

Cara lewat terminal, bila Vercel CLI sudah terhubung:

```bash
vercel --prod
```

## Catatan

Repo ini hanya berisi halaman portofolio kerja. Tidak ada data pribadi asli atau kredensial di dalam kode.
